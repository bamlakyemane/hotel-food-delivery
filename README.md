# Hotel Food Ordering & Delivery Platform

A full-stack web application for ordering food from a hotel restaurant, with separate customer, admin, and delivery-staff experiences.

## Tech Stack

**Frontend:** React 19, Vite, Tailwind CSS v4, React Router v7, Zustand, React Hook Form + Zod, Axios, Lucide, Framer Motion
**Backend:** Node.js, Express, MongoDB (added in Phase 4)
